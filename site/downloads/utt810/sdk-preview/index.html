Built and hardware-tested on Ubuntu 24.04 under WSL2 with USB forwarding. Follow the FTDI USB access instructions included in the README.

Included integration surfaces

C API and C++ integration

Include nexatomtt_c_api.h and link the native runtime library. C++ applications use the same C ABI.

Python package

Python wrapper and examples for loading the SDK, checking version information, booting an existing runtime slot, realtime smoke checks, and TIHI/MFCO workflows.

Preview documentation

Public preview documentation, license text, third-party notices, package manifest, and SHA256 verification file.

Start with the examples

Extract the SDK and run python python/examples/load_smoke.py --home . from its root. Use python3 on Linux when needed. The package README explains driver setup and the supported hardware workflows.

Use the standalone project in examples/sdk for C and C++, or the Python channel setup and processed/raw acquisition examples. They demonstrate threshold, edge, delay and hysteresis configuration, saving and offline analysis. Windows C/C++ examples use MinGW and the matching import library; Linux examples link the shared library.

This preview is tested on Windows and Ubuntu 24.04 under WSL2 with the bootloader-equipped Zynq running ZYNQ_004, using internal test pulses and digital input delays through 256 ns. One instrument is active at a time. Kintex and legacy Zynq hardware qualification for this preview, and external analog validation, remain pending.

Firmware safety note

The Python examples can boot an existing valid runtime slot when hardware is connected in bootloader mode. Firmware image loading is not part of normal SDK use and is limited to the advanced field-update example with explicit confirmation flags and overwrite guards.
